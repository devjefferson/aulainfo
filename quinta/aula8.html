Slide 2 · Hardware x Software
O corpo e o cérebro da máquina ⚙️🧠
🔧 Hardware

As peças físicas: tela, teclado, processador, memória.

🧠 Sistema Operacional

O software que faz todas as peças trabalharem juntas.

Sem sistema operacional, o hardware é só um monte de peças caras que não conversam entre si.

Slide 7 · Copiar, Mover e Lixeira
Organizando arquivos com segurança 🚚
📋 Copiar

O arquivo original fica onde estava, e uma cópia aparece no novo lugar.

🚚 Mover

O arquivo sai do lugar antigo e vai de vez para o novo lugar.

🗑️ Lixeira: um arquivo apagado não some de verdade — ele fica lá até você esvaziar.

🗜️
Slide 8 · Compactar em ZIP
Compactar arquivos em .zip 🗜️
.ZIP
🗜️ Compactar Pasta
Botão direito → Enviar para → Pasta compactada. Vários arquivos viram um só.
É como fazer uma mala: junta tudo num pacote só pra enviar mais fácil!

Ótimo para entregar um trabalho escolar com vários arquivos em um único envio.

🪟
Slide 9 · Snap Assist
Snap Assist — duas janelas ao mesmo tempo 🪟
⊞ + ← / →
🪟 Snap Assist
Arraste uma janela para a lateral e ela encaixa automaticamente na metade da tela.
Perfeito para copiar dados de um site direto pro seu trabalho!

Você já ficou perdido com muitas janelas abertas? O Snap Assist resolve isso.

🔄
Slide 10 · Alt+Tab e Mesas Virtuais
Trocando de janela e de "mesa" 🔄
🔄 Alt + Tab troca de janela
🗂️ Win + Tab Área de Trabalho Virtual

A Área de Trabalho Virtual cria uma "segunda mesa": uma área para escola, outra para lazer.

Slide 11 · Configurações
Configurações — os botões do sistema ⚙️
⊞ + I
⚙️ Configurações
Tela, som, Wi-Fi, contas — os ajustes do dia a dia ficam aqui.
O Painel de Controle é a versão mais antiga, com opções avançadas.

O Windows Update também mora aqui: o sistema se atualiza sozinho pra corrigir falhas de segurança.

Slide 12 · Gerenciador de Tarefas
Primeiros Socorros do PC 🚑
Ctrl+Shift+Esc
🚑 Gerenciador de Tarefas
Mostra todos os programas rodando e permite fechar o que travou.
Antes de desligar o PC no botão, tenta isso primeiro!
⚠️ Desligar o computador no botão sem salvar pode fazer você perder trabalho não salvo!

Slide 14 · Verdadeiro ou Falso?
Verdadeiro ou Falso? 🤔

Toque nos cards para ver a resposta!

"O Windows é um sistema operacional." ✅ Verdade!
"O Google Chrome é um sistema operacional." ❌ Falso! Chrome é um navegador.
"Um arquivo apagado vai para a Lixeira antes de sumir de vez." ✅ Verdade!
"Mover um arquivo cria uma cópia e mantém o original." ❌ Falso! Isso é o que Copiar faz. Mover tira do lugar antigo.
