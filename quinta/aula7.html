Slide 2 · A Turma do Ctrl
A Turma do Ctrl tem novos membros! 🦸‍♂️

Slide 3 · Ctrl + A
Ctrl + A — Selecionar Tudo! 🔲
Ctrl + A
🔲 Selecionar Tudo
Segura Ctrl → aperta A → tudo fica marcado!
É como abraçar todo o texto de uma vez! 🤗

Depois de Ctrl+A você pode:
Ctrl+C para copiar tudo · Ctrl+X para recortar tudo

Tente agora!
  • Escreva qualquer coisa → Ctrl+A → tudo selecionado!
✂️
Slide 4 · Ctrl + X
Ctrl + X — Recortar! ✂️
Ctrl + X
✂️ Recortar
Seleciona o texto → segura Ctrl → aperta X → sumiu!
É como arrancar o texto e guardar no bolso! 🎒

Use Ctrl+V logo depois pra colar no novo lugar!

Tente agora!
  • Escreva uma frase → Ctrl+A → Ctrl+X → frase sumiu!
  • Agora Ctrl+V para ela voltar! 🎩✨
🤔
Slide 5 · Copiar vs Recortar
Qual é a diferença? 🤔
📋 Ctrl + C

Copia o texto.
O original fica no lugar!

= tirar uma foto 📸

✂️ Ctrl + X

Recorta o texto.
O original some!

= arrancar e guardar 🎒

Ambos precisam de Ctrl+V pra colar depois! 👯

💾
Slide 6 · Ctrl + S
Ctrl + S — Salvar! 💾
Ctrl + S
💾 Salvar
Segura Ctrl → aperta S → arquivo salvo!
É como tirar o trabalho de casa antes que caia a luz! 💡

Dica de ouro: aperte Ctrl+S sempre!
Nunca vai perder seu trabalho de novo! ✅

Tente agora!
  • Abra o Bloco de Notas → escreva seu nome → Ctrl+S!
🕰️
Slide 7 · Ctrl+Z e Ctrl+Y
A Máquina do Tempo Completa! 🕰️
⏪ Ctrl + Z

Desfaz a última ação.

= volta no tempo ⏪

↪️ Ctrl + Y

Refaz o que foi desfeito!

= vai pra frente ↪️

Juntos são a máquina do tempo do computador! 🚀
Ctrl+Z → Ctrl+Z → Ctrl+Y → Ctrl+Y…

Tente agora!
  • Escreva algo → Ctrl+Z várias vezes → Ctrl+Y pra refazer!
🔍
Slide 8 · Ctrl + F
Ctrl + F — Procurar! 🔍
Ctrl + F
🔍 Procurar
Segura Ctrl → aperta F → digita a palavra → achou!
É o Google dentro do seu documento! 🌐

Funciona em qualquer lugar:
Word · Google Docs · Site · PDF

Tente agora!
  • Abra um site → Ctrl+F → procure uma palavra!

Slide 13 · Verdadeiro ou Falso?
Verdadeiro ou Falso? — Parte 2 🤔

Toque nos cards para ver a resposta!

"Ctrl+A seleciona todo o texto do documento." ✅ Verdade!
"Ctrl+X copia o texto e mantém o original." ❌ Falso! Ctrl+X recorta (remove o original).
"Ctrl+S salva o arquivo sem fechar." ✅ Verdade!
"Ctrl+Y desfaz a última ação." ❌ Falso! Ctrl+Y refaz. Quem desfaz é o Ctrl+Z.
