⚡ Teclas Especiais

As teclas modificadoras

Essas teclas não fazem nada sozinhas — mas combinadas com outras, fazem mágica:

  • Ctrl
    Control — a chave de atalho mais usada do teclado. Ctrl+C, Ctrl+V, Ctrl+Z, Ctrl+S... quase todo atalho passa por ela.
  • Alt
    Alternate — muda a função de outras teclas. Alt+Tab é o mais famoso: troca de janela sem usar o mouse.
  • Shift
    Shift — letras maiúsculas quando seguro, ou atalhos alternativos (Shift+Ctrl+Z = Refazer, Shift+Del = excluir definitivamente).
  • ⊞ Win
    Windows/Cmd — acessa o sistema. Win+D mostra o desktop, Win+L bloqueia o PC.
⚡ Teclas Especiais

As teclas de edição

  • Tab
    Tab — pula para o próximo campo num formulário. Em código, cria indentação. No navegador, cicla entre links da página.
  • Enter
    Enter — confirma ações, vai para a próxima linha, abre arquivos. É o "OK" do teclado.
  • ←⌫ Backspace
    Backspace — apaga o caractere antes do cursor (para trás). O mais usado para corrigir erros ao digitar.
  • Del
    Delete — apaga o caractere depois do cursor (para frente). Também exclui arquivos selecionados.
  • Esc
    Escape — cancela ações, fecha janelas, sai de modos. O botão "não, para tudo!" do teclado.
