Conceito base
🦠

O que é um Vírus de computador?

  • 💡Vírus = programa feito para causar dano
  • 📡Assim como gripe passa de pessoa para pessoa, vírus de computador passam de máquina para máquina
  • 🎭A maioria se disfarça de algo útil para enganar você
Tipo 1
📎

Vírus Tradicional

  • 🕵️Se esconde dentro de arquivos (jogos, filmes, programas)
  • ▶️Ativa quando você abre o arquivo
  • 🗂️Pode apagar, copiar ou criptografar seus dados
🎮 Exemplo real: Você baixa um "jogo grátis" de site desconhecido. Junto com o jogo, vem um vírus escondido que começa a rodar em segundo plano.
Tipo 2
🐴

Trojan — Cavalo de Troia

  • 🎁Parece algo útil — mas é uma armadilha
  • 🚪Abre uma porta secreta para o hacker entrar no seu PC
  • 👁️Pode espionar tudo que você digita (senhas, mensagens)
🏛️ A história original: Na Grécia antiga, soldados se esconderam dentro de um cavalo de madeira gigante para invadir Troia. O vírus faz a mesma coisa — entra disfarçado.
Tipo 3
🔒

Ransomware

  • 🔐Tranca todos os seus arquivos com uma chave que só o hacker tem
  • 💰Pede resgate em dinheiro para devolver o acesso
  • 🏥WannaCry (2017) travou hospitais — médicos não conseguiam ver prontuários
💸 Ransom = resgate em inglês. É um sequestro dos seus dados.
Tipo 4
🐛

Worm — Verme Digital

  • 🌐Se espalha sozinho pela rede — sem precisar que você clique em nada
  • 🔁Se replica automaticamente de máquina em máquina
  • 📶Pode travar redes inteiras só de se espalhando
🍕 Imagine: Uma corrente de WhatsApp que se manda sozinha para todos os contatos — sem você fazer nada.
Como se proteger
🛡️

Sua defesa digital

🔒
Antivírus atualizado
Detecta e bloqueia ameaças antes que causem dano
🔗
Não clique em links suspeitos
Email estranho, prêmio inesperado = armadilha
🏪
Fontes oficiais
Baixe apps só de lojas oficiais (Play Store, App Store)
🔑
Senhas fortes e únicas
Uma senha para tudo = uma chave para todas as portas

demo-worm.bat — Simula replicação de Worm
Cria 10 pastas dentro de %TEMP% e abre cada uma no Explorer — simulando a "explosão" visual de um worm. Deleta tudo no final. 100% inofensivo.
@echo off
echo Simulando replicacao de worm...
echo Serao abertas 10 janelas do Explorer — feche depois!
timeout /t 2 /nobreak

:: Cria pasta raiz da demo
mkdir "%TEMP%\aula_virus_demo" 2>nul

:: Cria cada subpasta e abre no Explorer imediatamente
for /l %%i in (1,1,10) do (
    mkdir "%TEMP%\aula_virus_demo\virus_copia_%%i" 2>nul
    echo Criando e abrindo copia %%i de 10...
    start explorer "%TEMP%\aula_virus_demo\virus_copia_%%i"
    timeout /t 1 /nobreak >nul
)

echo.
echo 10 janelas abertas! Isso e o que um worm faz —
echo se replica e "aparece" em varios lugares ao mesmo tempo.
echo.
echo Fechando tudo e limpando em 5 segundos...
timeout /t 5 /nobreak

:: Fecha todas as janelas do Explorer abertas pela demo
taskkill /f /im explorer.exe >nul 2>&1
timeout /t 1 /nobreak >nul
start explorer

:: Remove as pastas criadas
rmdir /s /q "%TEMP%\aula_virus_demo" 2>nul

echo Limpeza concluida! Nenhum dano causado.
echo LICAO: Worms reais nao se fecham sozinhos — o antivirus tem que fazer isso.
pause

  function boom() {
    const cx = innerWidth/2, cy = innerHeight/2;
    for (let i = 0; i < 200; i++) {
      const angle = Math.random() * Math.PI * 2;
      const speed = 4 + Math.random() * 14;
      particles.push({
        x:cx, y:cy,
        vx: Math.cos(angle)*speed, vy: Math.sin(angle)*speed - 6,
