Conceito base
🦠

O que é um Vírus de computador?

  • 💡Vírus = programa feito para causar dano
  • 📡Assim como gripe passa de pessoa para pessoa, vírus de computador passam de máquina para máquina
  • 🎭A maioria se disfarça de algo útil para enganar você
Tipo 1
📎

Vírus Tradicional

  • 🕵️Se esconde dentro de arquivos (jogos, filmes, programas)
  • ▶️Ativa quando você abre o arquivo
  • 🗂️Pode apagar, copiar ou criptografar seus dados
🎮 Exemplo real: Você baixa um "jogo grátis" de site desconhecido. Junto com o jogo, vem um vírus escondido que começa a rodar em segundo plano.
Tipo 2
🐴

Trojan — Cavalo de Troia

  • 🎁Parece algo útil — mas é uma armadilha
  • 🚪Abre uma porta secreta para o hacker entrar no seu PC
  • 👁️Pode espionar tudo que você digita (senhas, mensagens)
🏛️ A história original: Na Grécia antiga, soldados se esconderam dentro de um cavalo de madeira gigante para invadir Troia. O vírus faz a mesma coisa — entra disfarçado.
Tipo 3
🔒

Ransomware

  • 🔐Tranca todos os seus arquivos com uma chave que só o hacker tem
  • 💰Pede resgate em dinheiro para devolver o acesso
  • 🏥WannaCry (2017) travou hospitais — médicos não conseguiam ver prontuários
💸 Ransom = resgate em inglês. É um sequestro dos seus dados.
Tipo 4
🐛

Worm — Verme Digital

  • 🌐Se espalha sozinho pela rede — sem precisar que você clique em nada
  • 🔁Se replica automaticamente de máquina em máquina
  • 📶Pode travar redes inteiras só de se espalhando
🍕 Imagine: Uma corrente de WhatsApp que se manda sozinha para todos os contatos — sem você fazer nada.
Como se proteger
🛡️

Sua defesa digital

🔒
Antivírus atualizado
Detecta e bloqueia ameaças antes que causem dano
🔗
Não clique em links suspeitos
Email estranho, prêmio inesperado = armadilha
🏪
Fontes oficiais
Baixe apps só de lojas oficiais (Play Store, App Store)
🔑
Senhas fortes e únicas
Uma senha para tudo = uma chave para todas as portas

demo-rotacao.bat — Simula vírus que mexe na tela
Gira a tela em 90° → 180° → 270° → 0° repetindo o ciclo 5 vezes. Usa Ctrl+Alt+Seta do driver de vídeo. 100% inofensivo.
@echo off
:: Simula virus que fica rotacionando a tela sem parar
echo Simulando virus de rotacao de tela...
echo O ciclo vai rodar 5 vezes — aguente firme!
timeout /t 2 /nobreak

:: Macro de rotacao: Direita=90 | Baixo=180 | Esquerda=270 | Cima=0
set wsh=powershell -command "$wsh=New-Object -ComObject WScript.Shell; $wsh.SendKeys(

for /l %%c in (1,1,5) do (
    echo Ciclo %%c de 5...

    echo   90 graus
    powershell -command "$w=New-Object -ComObject WScript.Shell; $w.SendKeys('^%{RIGHT}')"
    timeout /t 2 /nobreak >nul

    echo   180 graus
    powershell -command "$w=New-Object -ComObject WScript.Shell; $w.SendKeys('^%{DOWN}')"
    timeout /t 2 /nobreak >nul

    echo   270 graus ^(-90^)
    powershell -command "$w=New-Object -ComObject WScript.Shell; $w.SendKeys('^%{LEFT}')"
    timeout /t 2 /nobreak >nul

    echo   0 graus ^(normal^)
    powershell -command "$w=New-Object -ComObject WScript.Shell; $w.SendKeys('^%{UP}')"
    timeout /t 2 /nobreak >nul
)

echo.
echo Fim! Tela restaurada para 0 graus.
echo LICAO: Um virus real faria isso infinitamente — sem voce conseguir parar.
pause

demo-worm.bat — Simula replicação de Worm
Cria 10 pastas dentro de %TEMP% e abre cada uma no Explorer — simulando a "explosão" visual de um worm. Deleta tudo no final. 100% inofensivo.
@echo off
echo Simulando replicacao de worm...
echo Serao abertas 10 janelas do Explorer — feche depois!
timeout /t 2 /nobreak

:: Cria pasta raiz da demo
mkdir "%TEMP%\aula_virus_demo" 2>nul

:: Cria cada subpasta e abre no Explorer imediatamente
for /l %%i in (1,1,10) do (
    mkdir "%TEMP%\aula_virus_demo\virus_copia_%%i" 2>nul
    echo Criando e abrindo copia %%i de 10...
    start explorer "%TEMP%\aula_virus_demo\virus_copia_%%i"
    timeout /t 1 /nobreak >nul
)

echo.
echo 10 janelas abertas! Isso e o que um worm faz —
echo se replica e "aparece" em varios lugares ao mesmo tempo.
echo.
echo Fechando tudo e limpando em 5 segundos...
timeout /t 5 /nobreak

:: Fecha todas as janelas do Explorer abertas pela demo
taskkill /f /im explorer.exe >nul 2>&1
timeout /t 1 /nobreak >nul
start explorer

:: Remove as pastas criadas
rmdir /s /q "%TEMP%\aula_virus_demo" 2>nul

echo Limpeza concluida! Nenhum dano causado.
echo LICAO: Worms reais nao se fecham sozinhos — o antivirus tem que fazer isso.
pause
demo-fugitivo.bat — Janela que foge do mouse
Abre um pop-up que foge da seta do mouse sempre que você tenta fechar. Simula adware que dificulta sua remoção. 100% inofensivo.
@echo off
echo Simulando virus que foge do mouse...
echo Tente clicar no botao OK — boa sorte!
timeout /t 2 /nobreak

powershell -NoProfile -Command "
Add-Type -AssemblyName System.Windows.Forms
Add-Type -AssemblyName System.Drawing

$screen = [System.Windows.Forms.Screen]::PrimaryScreen.WorkingArea
$rng    = New-Object System.Random

$form = New-Object System.Windows.Forms.Form
$form.Text            = 'VOCE TEM UM VIRUS GRAVE!!!'
$form.Size            = New-Object System.Drawing.Size(320, 160)
$form.StartPosition   = 'CenterScreen'
$form.TopMost         = $true
$form.FormBorderStyle = 'FixedDialog'
$form.BackColor       = [System.Drawing.Color]::FromArgb(30,0,0)
$form.ForeColor       = [System.Drawing.Color]::Red

$lbl = New-Object System.Windows.Forms.Label
$lbl.Text      = 'Clique em OK para remover o virus!'
$lbl.ForeColor = [System.Drawing.Color]::White
$lbl.Font      = New-Object System.Drawing.Font('Segoe UI', 10, [System.Drawing.FontStyle]::Bold)
$lbl.AutoSize  = $true
$lbl.Location  = New-Object System.Drawing.Point(20, 30)
$form.Controls.Add($lbl)

$btn = New-Object System.Windows.Forms.Button
$btn.Text      = 'OK — Clique aqui!'
$btn.Size      = New-Object System.Drawing.Size(140, 35)
$btn.Location  = New-Object System.Drawing.Point(85, 80)
$btn.BackColor = [System.Drawing.Color]::DarkRed
$btn.ForeColor = [System.Drawing.Color]::White

$btn.Add_Click({ $form.Close() })
$form.Controls.Add($btn)

$timer = New-Object System.Windows.Forms.Timer
$timer.Interval = 30
$timer.Add_Tick({
    $mouse = [System.Windows.Forms.Cursor]::Position
    $cx = $form.Left + $form.Width  / 2
    $cy = $form.Top  + $form.Height / 2
    $dx = $cx - $mouse.X
    $dy = $cy - $mouse.Y
    $dist = [Math]::Sqrt($dx * $dx + $dy * $dy)

    if ($dist -lt 180) {
        if ($dist -gt 1) {
            $speed = [int]([Math]::Max(60, (180 - $dist) * 1.2))
            $nx = $form.Left + [int]($dx / $dist * $speed)
            $ny = $form.Top  + [int]($dy / $dist * $speed)
        } else {
            $nx = $rng.Next($screen.Left, $screen.Right  - $form.Width)
            $ny = $rng.Next($screen.Top,  $screen.Bottom - $form.Height)
        }

        # Se bate na borda, teleporta para posicao aleatoria
        if ($nx -lt $screen.Left -or $nx -gt $screen.Right  - $form.Width -or
            $ny -lt $screen.Top  -or $ny -gt $screen.Bottom - $form.Height) {
            $nx = $rng.Next($screen.Left, $screen.Right  - $form.Width)
            $ny = $rng.Next($screen.Top,  $screen.Bottom - $form.Height)
        }

        $form.Left = $nx
        $form.Top  = $ny
    }
})
$timer.Start()
$form.ShowDialog() | Out-Null
$timer.Stop()
"

echo Conseguiu fechar! Nenhum dano causado.
